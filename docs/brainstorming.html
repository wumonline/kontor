Grundfunktionen

Das Fundament: Geld sehen, ordnen und verstehen.

Konten verwalten

Girokonto, Tagesgeld, Kreditkarte, Bargeld, Depot. Jedes mit eigenem Saldo und Gesamtvermögen oben.

Buchungen erfassen

Einnahmen, Ausgaben und Umbuchungen zwischen eigenen Konten, mit Datum, Betrag, Empfänger und Notiz.

Kategorien & Tags

Eigene Kategorien mit Unterkategorien (Wohnen › Strom). Tags für Querschnitte wie „Urlaub 2026“.

Automatische Zuordnung

Regeln wie „Empfänger enthält REWE → Lebensmittel“. Lernt aus deinen Korrekturen.

Übersicht / Dashboard

Daten rein

Import und Bankanbindung

Der größte Aufwand liegt meist hier. Je weniger Tipparbeit, desto eher wird die Software benutzt.

CSV-Import

Kontoauszüge von Sparkasse, ING, DKB, Comdirect usw. einlesen, mit Vorlagen pro Bank und Duplikat-Erkennung.

CAMT / MT940

Standardformate, die fast jede deutsche Bank exportiert. Zuverlässiger als CSV.

FinTS / HBCI direkt

Umsätze direkt von der Bank abrufen. Komplex (TAN-Verfahren, Registrierung bei der Deutschen Kreditwirtschaft).

Open-Banking-Dienst

Anbindung über einen PSD2-Anbieter (z. B. GoCardless, finAPI). Bequem, aber Daten laufen über Dritte und es fallen ggf. Kosten an.

Belege & Fotos

Kassenbon oder Rechnung als Bild/PDF an eine Buchung hängen. Später evtl. Texterkennung.

Export & Backup

Alles als CSV/Excel exportieren, Backup-Datei erstellen und wiederherstellen.

Pflicht

Import aus Quicken (QDATA)

Alle bisherigen Konten, Buchungen und Kategorien aus Quicken sollen übernommen werden. Die Originaldatei wird dabei nur gelesen und nie verändert.

Offener Punkt

QDATA ist ein nicht offengelegtes Format von Quicken. Ob es sich direkt lesen lässt, zeigt erst eine Kopie deiner Datei. Die Untersuchung läuft lokal, die Datei wird nirgendwo hochgeladen.

Weg A: QIF-Export verlässlich

In Quicken jedes Konto als QIF-Datei exportieren. QIF ist ein offenes Textformat mit Buchungen, Kategorien, Empfängern und Splitbuchungen. Funktioniert sicher, kostet aber einen Export-Schritt pro Konto.

Weg B: QDATA direkt wenn möglich

Die Datei einfach hochladen, und alles wird in einem Rutsch übernommen. Bequemer, aber nur machbar, wenn sich das Format zuverlässig entschlüsseln lässt.

  1. Hochladen

    QIF- oder QDATA-Datei im Browser auswählen. Sie bleibt auf deinem Server.

  2. Vorschau

    Gefundene Konten, Anzahl Buchungen, Zeitraum und Kategorien prüfen, bevor etwas gespeichert wird.

  3. Zuordnen

    Quicken-Kategorien den eigenen zuordnen oder 1:1 übernehmen. Doppelte Buchungen werden erkannt.

  4. Abgleich

    Endsaldo jedes Kontos mit dem Saldo in Quicken vergleichen. Abweichungen werden angezeigt.

  5. Rückgängig

    Jeder Import lässt sich komplett zurücknehmen, falls etwas nicht stimmt.

Sicherheit

So bleiben deine Finanzdaten geschützt

Der Server ist nur für dich da. Alles, was nicht nötig ist, bleibt zu.

Nicht aus dem Internet erreichbar

Keine Portfreigabe im Router. Von unterwegs nur über VPN: das in Unraid eingebaute WireGuard oder das Tailscale-Plugin.

Login

Passwort mit Argon2-Hash, optional zweiter Faktor per Authenticator-App. Sperre nach mehreren Fehlversuchen, automatische Abmeldung.

Verschlüsselt übertragen

HTTPS auch im Heimnetz, über einen Reverse Proxy wie Nginx Proxy Manager oder Caddy.

Verschlüsselt gespeichert

Unraid-Laufwerksverschlüsselung (LUKS) oder eine verschlüsselte Datenbank (SQLCipher).

Abgeschotteter Container

Läuft nicht als Root, sieht nur seinen eigenen appdata-Ordner und keine anderen Shares.

Backups

Täglich mit dem Plugin „Appdata Backup“, dazu eine verschlüsselte Kopie außer Haus (z. B. per rclone in die Cloud).
